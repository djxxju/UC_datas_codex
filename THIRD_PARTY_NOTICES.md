# Third-party data, software and citations

## PGLIB-UC

Upstream: https://github.com/power-grid-lib/pglib-uc  
Pinned commit: `39a7f38cf4703de92f0291f0c873c2e98c789301`  
Collection completed: 2026-10-15.

The 63 files under `UC_dataset/raw/pglib_uc/39a7f38cf4703de92f0291f0c873c2e98c789301/` are byte-identical to the upstream Git tree. This collection changes no original case parameters or source files. Catalogs, acquisition tools and inspection reports are separately generated by this project.

- Data: Creative Commons Attribution 4.0 International, https://creativecommons.org/licenses/by/4.0/ . Preserve source attribution, the license link, and disclose changes when making derived cases.
- Software: MIT, subject to the upstream copyright notice and license conditions.
- Full upstream license: [LICENSE](UC_dataset/raw/pglib_uc/39a7f38cf4703de92f0291f0c873c2e98c789301/LICENSE).
- Full upstream source overview and references: [README.md](UC_dataset/raw/pglib_uc/39a7f38cf4703de92f0291f0c873c2e98c789301/README.md).

The library is curated by the IEEE PES Task Force on Benchmarks for Validation of Emerging Power System Algorithms. Cite the library version/commit and the relevant original sources listed in its README. These include Knueven, Ostrowski and Watson on UC formulations; Krall, Higgins and O'Neill on the FERC test system; and Barrows et al. on the RTS-GMLC update. RTS-derived PGLIB cases have changed ramp rates and omit the original transmission network.

## CommaLAB UC collection

Official institutional page: https://commalab.di.unipi.it/datasets/uc/ . Four ready-made archives (RCUC, RCUC2, 118_UC, System_46buses) were downloaded locally. The reviewed page did not state an independent data redistribution license; this repository distributes factual descriptions, official URLs, collection receipts and download code, not a mirror of those archives. Citation details remain linked to the official bibliography. Generator `ucig.tgz` is not counted as a ready-made data package.

## Other sources

RTS-GMLC: https://github.com/GridMod/RTS-GMLC . It has custom data-use terms in the upstream README, and is not covered by the PGLIB license merely because PGLIB contains RTS-derived cases. The complete official v0.2.3 repository ZIP is now saved locally; this public repository supplies a pinned official download link and collection receipt. The ZIP preserves the upstream notices, source data and prepared tool formats, but does not include external Git submodule contents. Earlier partial raw files remain distinct from this archive. The custom notice permits redistribution subject to preservation and attribution requirements; the large archive is kept off this Git history for size reasons.

This repository does not relicense upstream materials as a single new dataset license.
