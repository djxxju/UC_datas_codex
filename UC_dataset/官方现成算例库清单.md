## 直接下载与批量采集

### UnitCommitment.jl

从项目根目录运行，只下载原文件并记录来源、大小和 SHA-256，不解压或解析算例：

```powershell
python UC_dataset/sources/collect_ucjl.py --family or-lib --family tejada19 --family matpower --no-proxy
```

`--no-proxy` 仅影响当前下载进程，可按本机网络情况省略。`--family matpower` 表示[已登记的 26 个代表日](sources/ucjl_available_instances.json)，不是全部全年场景。可以通过官方目录继续选择其他日文件；本轮没有把 365 日变体逐一下载。

官方分类入口：[OR-LIB 42 例](https://axavier.org/UnitCommitment.jl/0.4/instances/or-lib/)、[Tejada19 49 例](https://axavier.org/UnitCommitment.jl/0.4/instances/tejada19/)、[MATPOWER 26 个系统目录](https://axavier.org/UnitCommitment.jl/0.4/instances/matpower/)。

本次原件在本地 `UC_dataset/raw/unitcommitment_jl_0.4/`。外部服务器的独立数据再分发条款尚未明确，公开 GitHub 中保留事实性索引、原站链接和获取脚本。

## 如何理解数量与状态

- PGLIB-UC 原库与 UC.jl 的 56 个 PGLIB 转换条目同源，本轮没有重复下载后者。
- UC.jl 的 Tejada19 和作者 UC-data 是原始版/转换版关系，不叠加为两套独立基础系统；逐文件映射以后再做。
- RTS 在 PGLIB 中的无网络派生实例与完整 RTS-GMLC 官方包分别登记；预制工具格式不重复计为不同基础系统。
- 包、实例、系统与日场景分别统计，不把四个压缩包说成四个算例，也不把论文实验数量当作包内实测数量。
- 下载回执中的 SHA-256 仅识别保存的文件。此次没有数据参数检查、可行性/最优性验证或本机求解结果。

MATPOWER/NESTA 原始潮流数据、OPSD 时间序列及 OR-Library 原站生成器保留为后续补充来源；当前优先以上已经整理好的 UC 文件，不自行补参数。
