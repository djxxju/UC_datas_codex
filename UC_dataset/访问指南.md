# 仓库算例访问指南

核对日期：2026-10-18，第 09 批。当前 GitHub 保存十五个来源组的原件：PGLIB 目录加十四个数据附件；另两个已收集来源仅提供官方获取入口。来源数不等于独立系统数。

## 浏览与下载

1. 打开 [仓库首页](https://github.com/djxxju/UC_datas_codex)，先读 README。
2. 按研究用途查看 [分类索引](官方来源分类索引.md)，查版本和出处看 [官方总清单](官方现成算例库清单.md)。
3. 下载大包：打开 [Releases](https://github.com/djxxju/UC_datas_codex/releases)，展开某批的 **Assets**，点击有意义的数据文件名。下表也可直接下载。
4. `Source code (zip)` / `Source code (tar.gz)` 是 GitHub 自动生成的仓库源码包，不包含独立上传的 Release 附件。`git clone` 同样不会下载 Release 数据包。

## 只有入口、没有 GitHub 原件镜像的来源

- **UnitCommitment.jl**：已取得 OR-LIB42、Tejada19 49、MATPOWER 代表日26，共117文件；旧原件在本地。仓库提供 [实例 URL 索引](sources/ucjl_available_instances.json)及 [获取脚本](sources/collect_ucjl.py)。
- **CommaLAB**：旧本地已有 RCUC、RCUC2、118_UC、System_46buses 四包；通过 [官方入口与说明](reports/commalab_source_notes.md)获取。

这两个来源的独立再分发条款未明确，不能把索引当作已镜像数据。CUC-data、REAL Lab、Federalized Power Market UC、TAMU DemandResponse、PyPSA-stochUC、DyGTCN UC 和 Closed-Loop NCUC 是另外七个候选，只登记入口，原件尚未归档。TAMU 许可未明确，PyPSA-stochUC 论文热负荷未公开，见 [第 07 批说明](reports/cloud_sources_batch07.md)。

## 第 09 批解压后的入口

1. 从上表下载 Plan4Res 包；先解压外层，阅读 SOURCE_NOTICE.md 和 SOURCE_METADATA.json。
2. 阅读配套 D4.5 PDF，再按需解压内部 EDF 原 ZIP。内部文件名明确是 ReferenceWithoutClimateChange，只代表本次固定参考情景。
3. 保留数据与说明的两个 DOI。此包按一个来源组计，尚未转换或适配 COPT/Gurobi，详见 [第 09 批报告](reports/cloud_sources_batch09.md)。

## 第 08 批解压后的入口

1. openTEPES：先读根 README.md、LICENSE 与 doc/md/InputData.md；随包输入在 openTEPES/cases/，可从 9n 或 sSEP 目录开始。case_studies/ 是另附论文研究输入。
2. GenX：先读根 README.md、LICENSE，再进入 example_systems/ 下目标目录，连同 resources、system、policies、settings 一起保存；先读该例 README。
3. 两包都是官方模型与原始输入整包。17/11 是目录数，不代表独立整数 UC 系统数；线性松弛、政策罚项和 DC OPF 的区别见 [第 08 批报告](reports/cloud_sources_batch08.md)。COPT/Gurobi 适配尚未完成。

## 第 07 批解压后的入口

1. openSDUC：打开解压出的根目录，先读 README.md、LICENSE 与 `doc/md/InputData.md`；输入在 `openSDUC/16g`。保留整包的模型和文档，不只复制零散 CSV。
2. OPTIT：先读外层 SOURCE_NOTICE.md、SOURCE_METADATA.json，再按需解压 `base_instance.zip` 和 `data.zip`；设备描述与逐日输入一起使用。365 日不代表 365 个独立电网，单独时序包不能视作完整 UC 模型。
3. 两包都保留原格式，本轮只确认取得原件。COPT/Gurobi 的具体运行入口留待适配阶段确定；不要把“下载完成”当成“本机已可求解”。

## 使用状态

本库完成原件收集、出处和版本归档，全库统一仍未完成。[独立标准化仓库](https://github.com/djxxju/UC_database_sta)另有两个模型发生变化的派生试点，按其说明使用。COPT/Gurobi 适配、求解和基准解复现尚未完成。上游结果可作为参考材料，但不是本项目重新计算的结果。
