# 仓库算例访问指南

核对日期：2026-10-17。当前 GitHub 保存十个来源的原件：PGLIB 目录加九个数据附件；另两个已收集来源仅提供官方获取入口。来源数不等于独立系统数。

## 浏览与下载

1. 打开 [仓库首页](https://github.com/djxxju/UC_datas_codex)，先读 README。
2. 按研究用途查看 [分类索引](官方来源分类索引.md)，查版本和出处看 [官方总清单](官方现成算例库清单.md)。
3. 下载大包：打开 [Releases](https://github.com/djxxju/UC_datas_codex/releases)，展开某批的 **Assets**，点击有意义的数据文件名。下表也可直接下载。
4. `Source code (zip)` / `Source code (tar.gz)` 是 GitHub 自动生成的仓库源码包，不包含独立上传的 Release 附件。`git clone` 同样不会下载 Release 数据包。

## 只有入口、没有 GitHub 原件镜像的来源

- **UnitCommitment.jl**：已取得 OR-LIB42、Tejada19 49、MATPOWER 代表日26，共117文件；旧原件在本地。仓库提供 [实例 URL 索引](sources/ucjl_available_instances.json)及 [获取脚本](sources/collect_ucjl.py)。
- **CommaLAB**：旧本地已有 RCUC、RCUC2、118_UC、System_46buses 四包；通过 [官方入口与说明](reports/commalab_source_notes.md)获取。

这两个来源的独立再分发条款未明确，不能把索引当作已镜像数据。CUC-data、REAL Lab、Federalized Power Market UC 是另外三个候选，只登记入口，原件尚未归档。
