本批在 GitHub 托管运行器上直接从官方来源获取原文件，减少用户本机存储。各数据包内容保持上游原样；本项目仅添加来源与许可说明。没有做参数校验、模型转换或求解。

- **RTS-GMLC-v0.2.3.zip**：固定提交的完整官方仓库归档；保留上游自定义数据使用通知，不含外部 Git 子模块。
- **Tejada-UC-data-1b417ece.zip**：作者完整仓库归档，包括原始实例包、作者结果包、模型、工作簿及 MIT LICENSE。与已经归档的 Tejada 原件和 UC.jl 转换版本同源。
- **Stochastic-UC-solar-h7cnt32kys-v1.zip**：Doubleday、Hodge、Lara 发布的 7 个随机 UC 原文件，JSON/HDF5，DOI 10.17632/h7cnt32kys.1，CC BY 4.0。
- **Monash-capacity-expansion-UC-v2.zip**：Wijekoon、Liebman、Dunstall 在 Monash 发布的 6 个扩展规划 UC 原始工作簿，DOI 10.26180/5cdbde51bbb1b，版本 2，CC BY 4.0。属于含 UC 的扩展规划数据，不混称基础日前 UC。

引用、许可链接及来源地址见 **ATTRIBUTION.md** 与 **source_manifest.json**。**collection_receipt.json** 记录原文件与分发包的大小、SHA-256 和采集时间，仅用于身份追溯，不代表数据参数正确、可行或最优。
