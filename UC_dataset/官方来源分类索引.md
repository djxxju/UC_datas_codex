# 官方来源分类索引

更新：2026-10-18，第 10 批。此索引依据上游说明与文件目录分类，用于选材料；不是模型参数核验或求解验收。已有十七个来源组，其中十六个有至少部分 GitHub 原件；UC.jl 的 91 文件已镜像、26 文件待确认许可，CommaLAB 仍仅保留旧本地原件。来源数不等于独立电网数、实例数或软件库数。

| 来源 | 适合优先查找的材料 | 当前使用边界 |
|---|---|---|
| PGLIB-UC | 基础无网络 UC；56 个 48 小时 JSON | RTS 派生系列也不能当作含网络 SCUC |
| Comillas IIT openTEPES | 网络约束 UC 与运行/扩展规划，含储能、多能耦合及排放输入 | 17 个随包目录；RTS 重叠和同系统变体单列；默认模块/碳上限未核查 |
| GenX 官方示例 | UC 相关扩展规划、储能、CO2 政策、CO2 捕集 | 11 个目录；包含线性聚合 UC、政策松弛及 DC OPF，不能全标为整数 UC |
| Plan4Res / EDF CS3 | 欧洲系统 UC、季节储能价值、灵活性研究的公开数据和配套说明 | 固定参考情景 ReferenceWithoutClimateChange；内层未检查，不宣称所有气候/需求响应/碳约束情景已取得 |
| UnitCommitment.jl | OR-LIB、Tejada19、MATPOWER 扩展 UC | 已取 117 文件；OR-LIB42/Tejada19 49 共 91 文件已按 MIT 镜像，MATPOWER26 待确认许可；全年日场景未完整采集；不重复计 PGLIB/Tejada 同源项 |
| CommaLAB | 热电、水热与随机水热的作者原包 | 四个原包已在本地；独立再分发条款未明确 |
| RTS-GMLC | 含网络、时序与新能源的测试系统及预制格式 | 完整官方 v0.2.3；外部子模块不在 ZIP 内；未做工具导入测试 |
| Tejada UC-data | 作者 UC/SCUC 原实例、模型及参考结果 | 与 UC.jl Tejada19 同源；作者结果未复现 |
| Stochastic UC data files | 高比例光伏随机 UC 的 JSON/HDF5 | 七个文件共同构成研究数据，不计七个系统 |
| Monash 扩展规划 UC | 含 UC 的发电、网络、储能扩展规划 | 六个工作簿；不是统一的日前 UC JSON |
| HUST 水电 UC | 九组水电运行区间、流量与出力研究数据 | 九组为论文描述；96 个 15 分钟时段；没有逐表核验 |
| RPG Lab SCUC | IEEE24/73/118、合成 500 节点及 ML 研究样本 | 四类系统目录已确认；图文件、模型权重不计成独立 UC 算例 |
| JRC Dispa-SET EnVarClim | 区域 UC/调度，气候年、电源、水库、CO2 价格 | 区域传输模型；配置模板需后续设置；CO2 价格不等于排放总量约束 |
| Dispa-SET 部门耦合 | 欧洲部门耦合数据与配套模型版本 | 原作者关键词含电动车、热储能、水电；7z 未展开，不承诺每个场景都有所有功能 |
| TU Graz LEGO | 三份预制时间表示包；含 UC 的运行/规划模型 | 支持可选储能/需求侧管理/氢能等；未确认各默认实例的模块开关；PreviousData 与当前模型不兼容 |
| Comillas IIT openSDUC | 官方 16 机组 UC 示例、随机场景/运行备用/储能模型及 CSV 输入 | 17 个 CSV 为文件目录统计；不将排放输出等同碳总量约束；COPT/Gurobi 未适配 |
| OPTIT / 博洛尼亚 CHP–CHCP | 冷热电联供逐日需求/价格输入与配套 CHP 设备描述 | 两份 DOI 记录按一个来源组统计；365 日为作者描述；内层 ZIP 未展开，模型参数完整性未核验 |

“可用”目前只表示取得了上游原件及出处，不表示本机已经适配。COPT 是本机主求解器，Gurobi 是未来兼容目标；没有完成相关适配与求解测试。

需求响应、储能、碳约束的目标覆盖仍需进一步确认。第 08 批已加入 openTEPES 排放输入与 GenX 碳政策示例，但尚未核查实际开关、碳约束类型或是否为整数 UC，不能宣称硬碳总量约束基准已验收。LEGO 的需求侧管理能力、部门耦合包的热储能主题，以及 JRC 的 CO2 价格输入，不能直接填成“已经取得并验证独立需求响应/储能/碳总量约束 UC 标准基准”。国内省级完整合成系统也尚未取得。

TAMU DemandResponse 为合成 ERCOT/需求响应候选，许可未明确；PyPSA-stochUC 的论文热负荷未公开。两者只登记入口，不列入上表的已采集原件。

下载位置、固定版本与许可见 [官方原件总清单](官方现成算例库清单.md)和 [来源登记](sources/source_registry.json)。最新采集证据见 [第 10 批说明](reports/cloud_sources_batch10.md)；各原始包、上游模型与派生数据将持续分开保存。

第 09 批另登记 DyGTCN UC（拓扑变化/需求响应）和 Closed-Loop NCUC（预测优化）两个作者候选，许可未明确，未镜像数据；不计入已采集原件。
